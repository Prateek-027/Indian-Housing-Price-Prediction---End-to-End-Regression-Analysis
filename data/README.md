# Data

This folder contains the dataset used for the Indian Housing Price Prediction project.

## Dataset

- **Dataset:** Indian Housing Dataset
- **Type:** Synthetic dataset
- **Target Variable:** `price_lakh`
- **Records:** 10,025
- **Features:** Property characteristics, location attributes, amenities, accessibility, and other housing-related variables.

The dataset was created for educational and machine learning practice purposes and does not represent actual property listings or real-world transaction data.

## Key Variables

The dataset contains information such as:

- city
- locality_tier
- property_type
- area_sqft
- bedrooms
- bathrooms
- floor
- total_floors
- property_age_years
- parking_spaces
- distance_to_metro_km
- distance_to_school_km
- distance_to_hospital_km
- amenities_score
- crime_index
- monthly_maintenance_inr
- furnishing
- ownership_type
- price_lakh

## Usage

The dataset was used for:

1. SQL-based exploratory analysis and business insights.
2. Python-based exploratory data analysis.
3. Data cleaning and preprocessing.
4. Regression model development.
5. Model evaluation and comparison.
6. Feature importance and residual analysis.

The dataset is provided only for learning, demonstration, and portfolio purposes.
